# Triage labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the report |
| `needs-info` | `needs-info` | The report needs more information |
| `ready-for-agent` | `ready-for-agent` | The issue is specified well enough for an agent |
| `ready-for-human` | `ready-for-human` | The issue needs human implementation |
| `wontfix` | `wontfix` | The maintainers do not plan to act on the report |

Use the GitHub label in the middle column whenever a skill names the
corresponding role.
